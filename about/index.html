关于本站

Child9527 的主页由 GitHub Pages 自动托管，所有页面均通过 GitHub Actions 自动构建与部署。 本站包含软件中心、TVBox 工具集以及其他自动化内容，旨在提供稳定、持续更新的工具与资源。

自动化构建流程

本站的所有内容均由自动化脚本生成。你只需要维护 targets.json， GitHub Actions 会自动执行以下流程：

1. 检查上游仓库最新 Releases
2. 自动同步版本信息
3. 自动生成软件中心页面
4. 自动生成 TVBox 页面
5. 自动部署到 child9527.github.io

targets.json 说明

targets.json 是本站的核心配置文件，用于定义需要同步的软件列表、图标、简介、仓库地址等信息。 每次修改该文件都会自动触发同步与构建流程。

页面生成机制

- 软件中心页面（图标、简介、版本号、下载链接）
- TVBox 页面（接口、订阅源、配置文件）
- 首页导航与布局
- 本页面（About）
